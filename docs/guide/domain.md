# 绑定自己的域名

`workers.dev` 地址可以直接使用。想用自己的域名（比如 `panel.example.com`）：

1. 域名需要托管在同一个 Cloudflare 账号里。
2. 打开 Worker 的 **设置 → 域和路由** → **添加** → **自定义域**，填 `panel.example.com`。Cloudflare 会自动建好 DNS 记录和证书。
3. 用新域名打开面板，进入 **系统设置**，把 **面板地址** 改成 `https://panel.example.com` 并保存。

第 3 步决定服务器安装命令和订阅地址里写的是哪个地址。不填时，面板用你当前访问它的地址。

::: warning 改地址之后
已经接入的服务器记着旧地址。旧地址仍能访问时它们照常工作；要切换到新地址，在 **服务器** 页为它生成新的安装命令并在服务器上执行一次。订阅地址也会变成新域名，客户端里要更新。
:::
