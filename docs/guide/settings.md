# 系统设置和操作记录

![系统设置](/images/settings.png)

## 面板地址

服务器安装命令和订阅地址里写的面板地址。绑定了自己的域名后填在这里（见 [绑定自己的域名](./domain)）；留空则使用当前访问面板的地址。

## 网络测绘引擎

新建 REALITY 节点时"自动选择伪装目标"用的引擎和 API Key：Netlas、Quake（360）、ZoomEye 或 FOFA。Key 加密存放，页面上不再显示；只在查询时随任务发给那台服务器，服务器用完即弃，不写入磁盘。Netlas 有免费额度：在 app.netlas.io 注册后，从个人资料页复制 API Key。见 [节点 · 自动选择伪装目标](./nodes#自动选择伪装目标reality)。

## 运行信息

- **面板版本**
- **服务器同步间隔**（Worker 变量 `SYNC_INTERVAL`）
- **数据加密密钥**：来自 Worker 机密 `TOKEN_KEY`，或者面板自动生成（存在 D1）
- **管理员密码**：在 Cloudflare 控制台修改 Worker 机密 `ADMIN_PASSWORD`，所有已登录的会话随即失效
