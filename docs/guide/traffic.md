# 流量和限额

![流量](/images/traffic.png)

每台服务器统计自己节点的流量（Xray 节点用 Xray 的统计接口，其余节点用 iptables 计数），psm-agent 每 10 分钟把数字发给面板。**流量** 页显示：

- 本月总流量（从重置日起算，卡片上写着从哪天算起）、今日流量、超额暂停的节点数；
- 最近 30 天每天的流量：鼠标移到某一天上（手机上用手指点或划过，键盘上点一下图后用左右方向键），提示框里是当天的流量和日期。重置日之前的柱子是浅色的：那是上个月的流量，已经清零，不计入本月。仪表盘的“最近 14 天”也一样；
- 每个节点本月已用、上限、用量条、重置日、状态和多久以前更新的；可以搜索，点表头排序。

点 **立即刷新** 让所有服务器马上发一次（几秒后更新）。

::: tip 日期和时区
每天的统计按 **UTC 日期**（北京时间早上 8 点换日）；每月重置按**各服务器自己的时区**，在它的重置日零点。所以"今日流量"和服务器本地的"今天"可能差几个小时。
:::

## 流量上限

新建或编辑节点时填 **流量限制（GB，最多 1000000）** 和 **每月重置日**（1–28）：

- 0 表示不限制，只统计。
- 用量达到上限后，服务器自动暂停这个节点（拒绝新连接），面板上显示"超额暂停"，订阅里也不再出现它。
- 到每月重置日自动清零并恢复；也可以在流量页点 **重置**（或节点管理 ⋯ → 重置流量），立即清零并恢复。
- 服务器没能设好上限或清零时（比如防火墙规则加不上），节点上会显示原因，不会装作已经生效。
- 提高上限（或改成 0）也会解除暂停。

暂停和清零由服务器自己执行（PSM 的流量检查每分钟运行一次），面板离线也照常生效。

## 在服务器上查看

```bash
psm traffic list          # 各节点用量、上限、是否暂停
psm traffic reset <节点名> # 清零并恢复
```

独立安装的 Snell 和 SS2022 在这里分别叫 `snell` 和 `ss2022`。
